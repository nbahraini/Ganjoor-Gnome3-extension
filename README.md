# افزونه ی گنوم گنجور (Ganjoor gnome3 extension)

افزونهٔ GNOME Shell که روزانه و به‌صورت تصادفی یک **بیت** شعر از دیتابیس
SQLite گنجور در نوار بالای صفحه نشان می‌دهد و می‌تواند دیتابیس را به‌صورت
آنلاین از مخزن رسمی گنجور به‌روزرسانی کند.

## امکانات
- نمایش یک بیت کامل (دو مصراع) به همراه نام شاعر و عنوان شعر.
- انتخاب خودکار بیت تازه در بازهٔ دلخواه (پیش‌فرض هر ۲۴ ساعت / روزانه).
- دکمهٔ «بیتِ تازه» برای انتخاب دستی.
- به‌روزرسانی آنلاین دیتابیس با نوار پیشرفت (از جدیدترین ریلیز `ganjoor/desktop`).
- اعلان اختیاری هنگام تغییر بیت.
- صفحهٔ تنظیمات برای مسیر دیتابیس، بازهٔ زمانی و منبع به‌روزرسانی.

## پیش‌نیاز
- GNOME Shell نسخهٔ ۴۲ تا ۴۴.
- `python3` (برای خواندن SQLite و دانلود/استخراج دیتابیس؛ تقریباً همه‌جا نصب است).

## نصب
```bash
git clone https://github.com/USERNAME/ganjoor-beyt-gnome-extension.git
cp -r ganjoor-beyt-gnome-extension \
  ~/.local/share/gnome-shell/extensions/ganjoor-beyt@ganjoor.local
```
سپس پوستهٔ گنوم را ری‌استارت کنید (Wayland: خروج/ورود — X11: `Alt+F2` سپس `r`) و:
```bash
gnome-extensions enable ganjoor-beyt@ganjoor.local
```

## دیتابیس
- اگر فایل `ganjoor.s3db` را از «گنجور رومیزی» دارید، مسیرش را در تنظیمات بدهید.
- در غیر این صورت از منوی افزونه «به‌روزرسانی دیتابیس (آنلاین)» را بزنید؛
  دیتابیس در `~/.local/share/ganjoor/ganjoor.s3db` ذخیره می‌شود.

> توجه: فایل دیتابیس داخل این ریپو قرار نمی‌گیرد (در `.gitignore` است) چون
> حجیم است و متعلق به پروژهٔ گنجور می‌باشد.

## ساختار پروژه
```
metadata.json          مشخصات افزونه
extension.js           منطق اصلی و رابط نوار بالا
prefs.js               صفحهٔ تنظیمات (libadwaita)
ganjoor_helper.py      کوئری SQLite + دانلود/استخراج دیتابیس
stylesheet.css         استایل نمایش بیت
schemas/               اسکیمای تنظیمات (GSettings)
```
